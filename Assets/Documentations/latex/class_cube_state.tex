\doxysubsection{Detailed Description}
Represents the full logical state of a 3x3 Rubik\textquotesingle{}s Cube. 

The cube consists of 27 cubies stored in a fixed-\/size array. State updates occur in two stages:\+
\begin{DoxyEnumerate}
\item Permuting cubie positions (shuffling pointers in the array)
\item Updating cubie internal orientation (calling Apply\+Move on individual cubies) 
\end{DoxyEnumerate}
