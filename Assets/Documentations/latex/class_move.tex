\doxysubsection{Detailed Description}
Represents a single face rotation move on the Rubik\textquotesingle{}s Cube. 

A move consists of:\+
\begin{DoxyItemize}
\item face:\+ which face to rotate (0..5)
\item rev:\+ whether rotation is counter-\/clockwise (90 degrees CCW)
\item is180:\+ whether rotation is a double turn (180 degrees)
\end{DoxyItemize}

Moves are intended to be immutable after creation.
