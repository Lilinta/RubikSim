\doxysubsection{Detailed Description}
Responsible for creating and updating the visual representation of the Rubik\textquotesingle{}s Cube in Unity. 

This class reads \doxylink{class_cube_state}{Cube\+State} and updates Game\+Objects accordingly. It contains no cube logic.
