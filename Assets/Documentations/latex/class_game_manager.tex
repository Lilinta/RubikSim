\doxysubsection{Detailed Description}
Central controller of the game logic. Responsibilities:\+ 


\begin{DoxyItemize}
\item Maintain the current \doxylink{class_cube_state}{Cube\+State} (logical model).
\item Coordinate animation and rendering.
\item Apply moves safely (ensuring animations finish before next move).
\item Trigger solver and scramble sequences. 
\end{DoxyItemize}
