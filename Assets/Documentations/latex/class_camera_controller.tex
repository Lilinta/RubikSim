\doxysubsection{Detailed Description}
Controls camera orbit and zoom around a target point using Unity\textquotesingle{}s New Input System. 

Features:\+
\begin{DoxyItemize}
\item Mouse scroll to zoom in/\+out by adjusting camera field of view (FOV)
\item Right mouse drag to orbit the camera around a target position
\item Camera always looks at the target after movement
\end{DoxyItemize}

This script is purely for scene navigation and does not interact with the Rubik\textquotesingle{}s Cube logic.
