\doxysubsection{Detailed Description}
Generates random scramble sequences for the Rubik\textquotesingle{}s Cube. 

The generated sequence avoids:\+
\begin{DoxyItemize}
\item Two consecutive moves on the same face (e.\+g., R R)
\item Redundant patterns such as ABA where A and B are opposite faces belonging to the same axis group (e.\+g., U D U is invalid).
\end{DoxyItemize}

This produces more realistic and effective scrambles similar to official World Cube Association (WCA) rules.
