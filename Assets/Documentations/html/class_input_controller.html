Detailed Description

Temporary input handler used for testing cube interactions via keyboard. Only function when pkey is pressed.

This controller maps specific keyboard keys to Rubik’s Cube face moves and forwards them to GameManager for execution. It is designed for rapid debugging and development before the final mouse-based gesture input system is implemented.

Key mappings: F or 0 → Front face U or 1 → Up face R or 2 → Right face B or 3 → Back face D or 4 → Down face L or 5 → Left face

Holding the Shift key while pressing a face key will apply the move in reverse (counter–clockwise).

Pressing: K → Triggers a scramble sequence. S → Triggers a solving sequence Q → Debug Output

This script uses Unity's new Input System (UnityEngine.InputSystem) and checks for key presses every frame in Update.

Note: This controller is intended only for development and testing purposes. In the final version of the application, cube manipulation will be driven by mouse drag gestures and raycasting instead of direct keyboard input.
